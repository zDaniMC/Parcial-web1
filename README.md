# Hoja de Vida Web — José Daniel Rivas

Proyecto individual desarrollado para la asignatura **Programación en Ambiente Web I**
(Unidad Central del Valle del Cauca), correspondiente al ejercicio de construcción de
una hoja de vida (CV) web personal.

## Descripción

Página web de una sola vista que presenta un perfil profesional (con contenido
ficticio) organizado en las siguientes secciones:

- Información personal
- Perfil profesional
- Formación académica
- Experiencia
- Habilidades
- Proyectos
- Cursos y certificaciones
- Contacto y peronas

## Tecnologías utilizadas

- **HTML5**
- **CSS3**
- **[PicoCSS]
